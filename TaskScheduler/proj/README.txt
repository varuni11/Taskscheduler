Project 7: Task Scheduler with Priority Threads
Package: com.wipro.scheduler

RUN (needs Java 8+ installed):
  Linux/Mac : ./run.sh      (or: java -jar TaskScheduler.jar)

Source code is in the src/ folder (import it into Eclipse/IntelliJ if you like).
Main class: com.wipro.scheduler.service.TaskSchedulerService
